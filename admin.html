One-time setup

Connect the content database

This page is where projects, team members and stories are added. It needs a free Supabase project before it can sign anyone in.

  1. Create a free project at supabase.com.
  2. Open SQL Editor, paste supabase/schema.sql and run it.
  3. Open SQL Editor again, paste supabase/seed.sql and run it (loads the current content).
  4. Go to Authentication → Users → Add user and create an email + password for each editor.
  5. Open Project Settings → API, copy the Project URL and the anon public key.
  6. Paste both into js/config.js and reload this page.

Full instructions with screenshots-in-words: SUPABASE.md. Never put the service_role key in the website.
